Hugginface [ai agents course](https://huggingface.co/learn/agents-course/en/unit0/introduction) is a good place to go as well. BUT, it does not give you a critical view on things that I, for example, am very critical about, such as agents vs workflows, context engineering, autonomous vs flows, tools vs structured outputs, etc. But will learn immensely. Try not to stick to a framework too much tho.

Good lib to use ai in typescript: [ai-sdk](https://ai-sdk.dev/docs/introduction) good abstraction to use multiple providers, tool calling, integrating with frontend etc. While giving you control. -> Quick course on it here: [ai-sdk-course](https://www.aihero.dev/what-is-the-ai-sdk) - super amazing typsecript guy

But openai sdk is also good, has everything you'd need, less abstractions.

For python I recommend just openai sdk.

Ofc [AI Engineering by chip huyen](https://www.oreilly.com/library/view/ai-engineering/9781098166298/) - good resource for those who want to take it seriously, deeper dive, understand the timeless concepts behind it, testing, data, prompts, agents, flows etc.

O curso de agentes de IA da Huggingface — [AI Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction) — também é um bom ponto de partida. MAS ele não oferece uma visão crítica sobre aspectos dos quais, por exemplo, sou bastante crítico, como agentes versus fluxos de trabalho, engenharia de contexto, autônomos versus fluxos, ferramentas versus saídas estruturadas etc. Ainda assim, você aprenderá imensamente. Procure não se apegar demais a um único framework.

Boa biblioteca para usar IA em TypeScript: [ai-sdk](https://ai-sdk.dev/docs/introduction) — oferece uma abstração para múltiplos provedores, chamadas de ferramenta, integração com frontend etc., mantendo o controle nas suas mãos. → Curso rápido sobre ela aqui: [AI-SDK Course](https://www.aihero.dev/what-is-the-ai-sdk) — o cara por trás é sensacional em TypeScript.

Mas o SDK da OpenAI também é ótimo, tem tudo o que você precisa, só com menos abstrações.

Para Python, recomendo usar apenas o SDK da OpenAI.

Claro, [AI Engineering by Chip Huyen](https://www.oreilly.com/library/view/ai-engineering/9781098166298/) é um excelente recurso para quem quer levar o tema a sério — mergulho profundo para entender conceitos atemporais como testes, dados, prompts, agentes, fluxos etc.
